---
title: XLine Tool
description: Xcode source editor extension adding a couple shortcuts
---

This is an xcode extension I have been maintaining for years, across multiple iterations of the xcode plugin system.
It adds a few keyboard shortcuts that I feel xcode should implement natively, but which do not exist.

More specifics can be found on the [project github](https://github.com/p3l6/XLineTool).

> [!NOTE] Install
> This app can be installed via homebrew: `brew install p3l6/tap/xline-tool`
